تحديث مكتبة الهندسة الرقمية v4.5
================================

الميزات الجديدة:
- إرفاق ملف عند إنشاء مهمة، وعرضه للموظف.
- محادثة بين الطالب والمكتبة مع إرسال ملفات.
- تحويل ملف المحادثة إلى طلب طباعة، أو إنشاء مهمة من المحادثة.
- إشعارات للطلاب أو الموظفين أو الجميع.
- تسجيل المبلغ المسدد لكل شريك، مع المتبقي وتاريخ وطريقة التسديد.
- إغلاق يومي لمنفذ POS: النقد والبطاقة الخضراء والبطاقة السوداء.
- شاشة إدارة النظام للمدير فقط.
- تغيير كلمة مرور أي موظف بواسطة المدير.
- حذف قسم أو مرحلة بواسطة المدير، مع منع حذف العناصر المرتبطة بملازم حمايةً للبيانات.

طريقة التحديث:
1) ارفع ملفات هذه النسخة إلى مستودع GitHub واستبدل الملفات القديمة.
2) افتح Supabase ثم SQL Editor.
3) نفذ الملف database/online_upgrade.sql كاملاً مرة واحدة.
4) انتظر اكتمال النشر في Render، ثم حدّث المتصفح بواسطة Ctrl+Shift+R.

مهم:
- لا ترفع ملف .env إلى GitHub.
- تغيير كلمات المرور وحذف الأقسام والمراحل موجود في: لوحة المدير > إدارة النظام.

تحديث النسخة 4
================

1) ارفع ملفات المشروع إلى مستودع GitHub واستبدل الملفات القديمة.
2) افتح Supabase ثم SQL Editor.
3) شغّل الملف database/online_upgrade.sql مرة واحدة.
4) انتظر Render حتى ينتهي النشر وتظهر الحالة Live.

الميزات الجديدة:
- إخفاء رابط عرض وتحميل الملازم عن الطلاب.
- تسجيل طلب طباعة الملزمة في قائمة الكادر.
- اختيار عدة ملفات أو صور ورفعها دفعة واحدة.
- طباعة هوية برفع الوجه والظهر وعرضهما جنباً إلى جنب بمقاس الهوية القياسي على A4.

ملاحظة أمنية:
لا ترفع ملف .env إلى GitHub ولا تشارك مفاتيح Supabase أو كلمات المرور.

تحديث مكتبة الهندسة الرقمية v4.6
================================

- واجهة الملازم أصبحت مخصصة للأقسام والمراحل والملازم فقط.
- شريط سفلي بثلاث بوابات: الملازم، الطلاب، الكادر والإدارة.
- بوابة الطلاب تضم رفع ملفات الطباعة والدردشة والملازم.
- شاشة المدير تعرض الإشعارات الفعالة مع زر إزالة لكل إشعار.
- تصفير تشغيلي منفصل للمحادثات، والإشعارات، وملفات الطباعة المنجزة، والمهام المنجزة.
- التصفير عبارة عن أرشفة آمنة، ولا يحذف الحسابات المالية أو POS أو تسديدات الشركاء.

طريقة التحديث:
1) ارفع محتويات هذه النسخة إلى GitHub واستبدل الملفات القديمة.
2) لا ترفع ملف .env إلى GitHub.
3) افتح Supabase > SQL Editor ونفذ database/online_upgrade.sql كاملاً مرة واحدة.
4) انتظر اكتمال النشر في Render ثم حدّث الصفحة بواسطة Ctrl+Shift+R.

ملاحظة: افتح رابط التطبيق على الموبايل بواسطة Chrome أو Safari، وليس داخل متصفح واتساب.
